# Java Completo: Programação Orientada a Objetos + Projetos

Este repositório contém uma coleção de projetos e exercícios práticos decorrentes do curso "Java COMPLETO Programação Orientada a Objetos + Projetos" oferecido na Udemy. O curso aborda conceitos fundamentais da programação orientada a objetos, além de fornecer projetos práticos que ajudam a consolidar o aprendizado.
Um agradecimento especial ao professo Nelio Alves por compartilhar seu conhecimento de forma tão sólida e 
rica. (https://github.com/acenelio)

## Objetivos do Repositório

- **Aprender os conceitos de OOP:** Entender classes, objetos, herança, polimorfismo e encapsulamento.
- **Desenvolvimento de Projetos:** Criar projetos reais para aplicar o conhecimento adquirido.
- **Integração com Git e GitHub:** Praticar o versionamento de código e colaboração em projetos.
- **Documentação e Manutenção:** Expandir o conhecimento em boas práticas de codificação e documentação de projetos.

## Estrutura do Repositório

- `Projeto1/`: Descrição do primeiro projeto.
- `Projeto2/`: Descrição do segundo projeto.
- `Documentacao/`: Links e materiais úteis relacionados ao curso.
